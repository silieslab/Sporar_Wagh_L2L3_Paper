This directory contains the scripts used to generate the figure panels, with each filename corresponding to its respective panel.
Before running the scripts:
1. Set your working directory to this folder's path.
2. Add all subfolders within this directory to your search path.
3. Update the pdatapath variable to point to your local pdata directory.
